# 🗺️ Agcabedi GIS Spatial & Terrain Analysis

A comprehensive GIS project focusing on spatial distribution, hydrological mapping, and terrain analysis for the Agcabedi region using QGIS.

---

## 📊 Project Overview
This project integrates vector data, coordinate shapefiles, and raster terrain models to analyze geographical features, regional connectivity, and surface characteristics of the Agcabedi area.

---

## 🛠️ Layers & Data Structure
* **Raster Layers**:
  * `Slope`: Terrain steepness and gradient analysis.
  * `Aspect`: Directional slope exposure mapping.
  * `Agcabedi_DEM`: Digital Elevation Model used for surface modeling.
* **Vector Layers**:
  * `Agcabedi_rivers`: Hydrological network mapping.
  * `Agcabedi_City`: Boundary and settlement features.
  * Point feature shapefiles (Coordinate-based datasets for regional distribution and network analysis).
* **Base Map**: OpenStreetMap (OSM Standard) integration for geographic context.

---

## 💻 Software & Tools
* **Software**: QGIS 3.x
* **Key Modules**: Processing Toolbox, Raster Terrain Analysis, Vector Analysis Tools.
